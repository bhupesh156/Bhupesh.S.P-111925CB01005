# Factorial Program in C

## Program Details

* **Language:** C
* **Program:** Factorial of a Number
* **Input:** An integer number
* **Output:** Factorial of the given number

## Example

**Input:**

```text
5
```

**Output:**

```text
Factorial of 5 = 120
```

## Logic

The factorial of a number `n` is calculated as:

```text
n! = 1 × 2 × 3 × ... × n
```

For example:

```text
5! = 1 × 2 × 3 × 4 × 5
   = 120
```

## Complexity

* **Time Complexity:** O(n)
* **Space Complexity:** O(1)
